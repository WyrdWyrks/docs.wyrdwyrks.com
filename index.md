# WyrdWyrks Docs

Documentation for WyrdWyrks hardware and firmware projects.

## Celestial Wayfinder

The Celestial Wayfinder is a DEF CON badge built around an ESP32-S3, with a
BQ25672 PMIC, LoRa radio, GPS, and an OLED display.

See [Celestial Wayfinder]({% link celestial-wayfinder/index.md %}) for the full
documentation, starting with the
[User Guide]({% link celestial-wayfinder/user-guide.md %}).
